# MP-BLIPW

This repository contains the R code accompanying the manuscript on
Multiphase-BLIPW (MP-BLIPW) for regression analysis with missing covariates
under multiphase sampling designs.

## Repository Structure

### Simulation Study

The simulation code evaluates the performance of:

- SIPW
- BLIPW
- MP-BLIPW

under different multiphase sampling scenarios.

### NHANES Application

The empirical analysis applies MP-BLIPW to NHANES data to investigate the
association between HDL cholesterol and DEXA-measured body fat percentage.

Hip circumference is used as auxiliary information in the multiphase design.

## Software

Analyses were conducted using R.

## Reproducibility

Run the R scripts in numerical order.
